PacketGlow ops and your Google data

PacketGlow ops is a private command-line tool that publishes videos to the PacketGlow channel and reads that channel's analytics. Its only user is the channel owner, signing in to their own channel. It requests these Google OAuth scopes:

  • youtube.upload: upload the channel's videos and thumbnails;
  • youtube and youtube.force-ssl: set video details, captions, playlists and the pinned comment on the channel's own videos;
  • yt-analytics.readonly: read the channel's own analytics and reach reports (views, watch time, retention, impressions).

What happens to that data:

  • Storage: the sign-in token is stored only on the owner's computer (~/.config/packetglow, readable by the owner only) and, for scheduled jobs, as an encrypted secret in the owner's private GitHub repository. Channel analytics are saved as files in that private repository to compare videos over time.
  • No sharing or selling: no data is sold, shared with third parties, used for advertising, or used to train AI models.
  • Revoking access: remove PacketGlow ops at any time at Google Account → Third-party access, or security.google.com/settings/security/permissions. Deleting the token file and the repository secret removes the stored copies.

PacketGlow ops' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

PacketGlow ops uses YouTube API Services. By using them you are bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

For research, the tool also reads public statistics of other YouTube channels (titles, view counts, durations) with an API key. Those statistics are cached for at most 30 days and then deleted. No personal data of viewers is collected.

This website and the channel

This website sets no cookies, runs no analytics or tracking, and has no forms. Watching the channel on YouTube is governed by YouTube's own terms and privacy policy; PacketGlow sees only the aggregated, anonymous statistics YouTube Studio shows every creator.
